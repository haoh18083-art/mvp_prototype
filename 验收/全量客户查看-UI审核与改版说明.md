# 全量客户查看：UI 与表格改版

日期：2026-09-09  
页面：P-ADM-22，`pages/customers.html`

## 页面定位

超管查询全量客户档案，以检索、筛选、横向比较、展开经营组合为主要任务。桌面优先，兼顾小窗口。页面使用统一白底、浅灰表头和细分隔线，以排版建立层级；不采用 CRM 总览页的大面积深蓝或琥珀色区域。

## 原有问题与调整

| 原有问题 | 影响 | 本次调整 |
| --- | --- | --- |
| 统计区高、说明重复，合并档案开关单独占据页面上方 | 查询和表格被推向下方 | 统计压缩为一行；开关移动至客户列表工具区 |
| 八个筛选控件同时铺开，多选原生列表与单选框高低不齐 | 视觉零散，多选方式不直观 | 常用区域保留搜索、销售分组、客户池、来源；其余放入“更多筛选”；两项多选使用复选框下拉面板 |
| 表格没有按内容分配列宽 | 客户名称、多个客户池、操作列相互挤压 | 客户列占 25%，其余列按信息长度分配；表格设置最小宽度并在自身容器横向滚动 |
| 每行重复客户图标、来源状态点和按钮边框 | 装饰元素抢占阅读注意力 | 客户主名称与次级编号分层；来源改为普通文字；分组与池采用浅灰小标签；展开改为文字操作 |
| 数量“3 / 0”与表头缺乏稳定对齐 | 多行比较困难 | 已归属／空余数字使用等宽数字、固定间隔与右对齐；公海居中；操作右对齐 |
| 展开区嵌套白色条块、间距大 | 主行与子内容关系不清楚 | 浅灰底、细左侧引导线和紧凑空间行；展开后显示“收起”并更新箭头、aria-expanded |
| 合并档案开关重写查询参数 | 当前人员参数丢失 | 使用 URL 参数增量更新，保留 role 和 as |

## 控件与状态

- 复用原有共享表格的搜索、筛选、分页、sessionStorage 恢复和统计刷新；多选仍为同一字段内满足任一选项，不同字段同时满足。
- 分组筛选项从现有客户归属关系生成，能够展示当前分组名称。
- “更多筛选”显示当前生效的附加条件数，折叠不取消筛选；重置清空全部条件。
- 多选支持清除本项、点击外部收起、Escape 收起并返回焦点；已选数量显示于收起的控件中。
- 保留客户明细、经营组合、空间只读查看和分页入口；无结果保持明确空态；非超管沿用无权访问逻辑。
- 表格桌面下固定客户列与操作列；窄屏取消固定列，使用容器内滚动。主要移动端筛选触摸区域最小 44px。
- 视觉取值：白色主体、`#f8f9fb` 表头、`#e4e7ec` 分隔线，正文与辅助文字分级，蓝色主要用于可点击项与焦点。没有新增强色差的业务分区。

## 字段与业务范围

客户、来源、归属人、销售分组、客户池、已归属／空余商机、阶段、等级、公海和经营组合均沿用原数据。前三项统计继续随当前筛选刷新；待合并对仍为全局统计，显示“全局”。不新增编辑、删除、分配、裁决或业务数据写入操作。

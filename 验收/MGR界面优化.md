# MGR 界面与交互优化

范围：销售主管 8 个导航入口、4 个原三级页面，以及可达的经营组合、客户档案、商机、客户工作空间和历史空间。沿用超管的浅灰背景、白色内容区、蓝色操作、状态标签与右侧抽屉。

## 逐页问题与调整

| 页面 | 原问题 | 已调整 |
| --- | --- | --- |
| 工作台 | 指标含重复口径说明，待办权重不足；失败列表复选框占用宽列 | 核心数据集中为客户、销售、已激活商机和待配置商机；待办可点击；恢复标签显示数量；修正选择列 |
| 客保审批 | 查看申请、空余分配跳离清单；缺少历史切换 | 待审批／已处理标签；分配入口和标签同行；申请、分配原位抽屉 |
| 客保审批详情 | 表单和操作散落在整页；审批字段同时启用 | 复用审批业务渲染；固定底部提交；按处理结果启用客户池或驳回原因；关联商机和组合逐级抽屉 |
| 空余商机分配 | 独立三级页与客保来回跳转 | 客保列表打开分配抽屉；保留多选、承接销售范围、逐条分配和结果反馈 |
| 本组销售 | 只有平铺数字；查看客户跳转；长表头降低扫描效率 | 增加账号概览、状态筛选、简短表头；按销售打开客户抽屉 |
| 本组客户 | 缺少销售和客户池筛选；当前与历史同时堆叠；按销售进入后历史范围不一致 | 客户／组合指标；增加销售与客户池筛选；当前组合／历史空间标签；历史遵守同一销售范围；提供清除销售范围入口 |
| 商机管理 | 查看和调整客户池分列；复选框列过宽；批量栏常驻 | 合并操作列并固定在右侧；增加销售、客户池、经营结果筛选；商机详情抽屉；选中后显示批量操作 |
| 跟进准入终审 | 待办、详情和已处理记录互相跳页；空白选择列 | 待终审／本人已处理标签；原位终审抽屉；固定操作；条件不足时禁用通过并展示原因 |
| 准入终审详情 | 查看商机继续离开当前终审 | 商机、空间逐级覆盖，返回恢复原终审意见和滚动位置 |

| 异常处理 | 缺少各类问题数量；查看和处理分列 | 标签显示数量；操作列合并；商机详情抽屉；Agent 恢复入口与标签同行 |

| 经营组合 | 关联档案、商机、空间会跳页 | 复用组合业务内容；关联实体统一打开下一层抽屉，循环查看返回已打开层级 |
| 客户档案 | 从组合进入即打断上下文 | 提供档案抽屉中的基础信息、联系人、本组商机、来源、历史；原档案页仍可访问，其商机按钮也打开抽屉 |

## 统一规则

- 一层抽屉记录在当前 URL；刷新可重新打开。旧主管详情链接跳到对应清单并打开指定记录；旧已处理链接跳到记录标签。
- 子抽屉与父抽屉同宽（最大 880px，小屏占满窗口），从右向左滑入。顶部返回、关闭、Esc 和遮罩关闭作用于当前层；关闭后恢复焦点。
- 查看详情不重绘清单，保留搜索、筛选、页码和当前选择；子抽屉查看不重绘父表单。
- 表格筛选缓存按页面、主管人员和表格隔离。复选框独立窄列，数字列靠右；表格内部横向滚动，操作列固定。
- 审批／准入提交沿用既有模型、权限和版本校验，成功后同步清单与详情。失去任职或本组权限时关闭不可访问详情。
- 没有新增审批监督的虚构数据；保留现有恢复与调整客户池确认流程。

## 实现与验证

主管交互集中在 `js/batch3/manager.js`，视觉集中在 `css/manager.css`；共享审批、准入、组合、商机、空间渲染器继续复用。空间渲染器增加显式 `spaceId`，客户历史增加销售范围校验。

自动验证入口：

```sh
node --test tests/manager-ui.cjs tests/customers-combo.cjs tests/verdict-drawer.cjs tests/product-drawers.cjs tests/admission-drawer.cjs tests/page-navigation.cjs
```

覆盖主管全部导航页、详情深链、旧链接、父子抽屉、焦点恢复、筛选保留、表单联动、准入提交、失效权限与其他角色既有抽屉。浏览器额外核对实际布局、固定底部、滑入覆盖与返回。

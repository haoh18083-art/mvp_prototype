PRD-04
原型约定
原型脚手架，不是产品 UI——以下两处仅用于原型导航，实现时应移除：
· 侧栏菜单右侧的「批2／批3／空」标记，用于标注该页面属哪个交付批次；
· 顶部的「原型角色」下拉，用于切换查看四套角色菜单。产品中一人只对应一种角色。

数据——全部为虚构样例，不含真实客户或人员信息。批 2 筛选、分页、批量选择与操作结果为本地交互；不连接真实 CRM。

目录结构——css/（tokens · base · layout · components · pages）、 js/（data · menu · components · layout）、 js/pages/（每页面一个）、 pages/（每页面一个 HTML）。 主框架由 js/layout.js 统一注入，页面 HTML 只声明容器。
